Quando conjurar uma magia que cause dano, você pode gastar **1 ponto de feitiçaria** para refazer uma quantidade de dados de dano de sua escolha, até o seu modificador de Carisma. Você deve usar os novos resultados.

Para Saika, isso significa que ela pode refazer até **3 dados de dano** de uma magia, como *Mãos Flamejantes* ou *Raio Ardente*, quando o resultado não for bom.
